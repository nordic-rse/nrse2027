# Nordic-RSE conference template

Template for Nordic-RSE conference website . Based on [Academic Workshop](https://aterenin.github.io/academic-workshop), a Zola theme designed for hosting a website for scientific workshop or scientific seminar series.

Find all places with XX and update with your conferences information. 

## Build a local preview

Easiest to use Apptainer/Singularity

``` bash
apptainer pull docker://ghcr.io/getzola/zola:v0.19.1
apptainer run zola_v0.19.1.sif serve
```
